# Writing an ADR

1. Find the next number in docs/adr/ (zero-padded, e.g. 004).
2. Copy template.md from this folder to docs/adr/NNN-short-title.md.
3. Fill every section. "Alternatives considered" must list at least two real
   options with honest trade-offs, not strawmen.
4. Keep it under one page.
5. Link it from the ADR index in docs/architecture.md.
